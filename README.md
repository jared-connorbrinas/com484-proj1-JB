# Coffee & Café Guide

## Live Demo

## Synopsis
A simple, beginner-friendly coffee website created as a web development project. The site is designed to help new coffee drinkers learn about common café drinks, discover cafés, and explore recommended coffee-related products and resources.

## Features

- Beginner-friendly coffee drink guide
- Drink ratios and descriptions for:
  - Espresso
  - Cortado
  - Cappuccino
  - Flat White
  - Pour Over
  - Other popular café drinks
- Café guide with recommended coffee shops
- Favorites page for highlighted drinks, cafés, and products
- External resource links for learning more about featured products and cafés
- Embedded/interactive links designed to keep users connected to the main site experience
- Modern café-inspired typography and styling
- Interactive UI elements inspired by ReactBits
- Responsive layout for different screen sizes

## Project Pages

- `index.html` — Home page and introduction to the site
- `cafes.html` — Café guide and recommended coffee shops
- `drinks.html` — Coffee drink guide, descriptions, and ratios
- `favorites.html` — Personal favorites and featured recommendations

## Technologies Used

- HTML5

- JavaScript
- ReactBits-inspired UI effects and components

## How to Run the Project

1. Download or clone the project folder.
2. Keep all HTML, CSS, JavaScript, and image files in their correct folders.
3. Open `index.html` in a web browser.

For the best experience while developing, the project can also be opened with a local development server such as the **Live Server** extension in Visual Studio Code.

## Project Goal

The goal of this project is to create a visually appealing and useful café guide for people who are new to coffee. Instead of only listing drinks, the site explains common coffee-to-milk or coffee-to-water ratios so visitors can better understand what they are ordering.

The café section also connects users with real coffee shops and resources so they can continue learning about coffee culture.
